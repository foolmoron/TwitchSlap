# TwitchSlap

Godot 4.7 multiplayer mobile game using WebRTC (following AndrooDev's tutorial: https://github.com/jonandrewdavis/AndrooDev-Friendslop-Co-Op-Tutorial-Part-2)

Some files used 5.6 Sol assistance

### Local https

`npx --yes http-server -S --cert="cert.pem" --key="key.pem" -P https://api.androodev.com -c-1`
